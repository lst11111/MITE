# MITE

## Environment

1. Create a new **conda** environment

    ```bash
    conda create --name mite_env
    ```

2. Activate the newly created environment

    ```bash
    conda activate mite_env
    ```

3. Install the required modules

    ```bash
    pip install -r requirements.txt
    ```

## Convert original data to multiple programming languages


    python change_data2c.py
    python change_data2java.py
    python change_data2python.py

## Train 

    python main.py


## Datasets

All datasets can be found in the [NERLlama3.1](https://github.com/liuhhuink/NERLlama3.1).
